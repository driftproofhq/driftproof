# reports/

This directory is the future home of **public drift reports** — periodic,
model-version-bound comparisons of how skills hold up as models change.

## What lives here

- **`example-drift.md`** — a worked drift report between two receipts of the
  example skill (`examples/commit-message-conventions`), generated by
  `driftproof diff`. It demonstrates the band-overlap verdict logic on real data.
- **`example-receipts/`** — the sampled receipts those reports are built from,
  kept as reference artifacts you can re-validate with `driftproof validate`.

## What's coming (see the roadmap in the top-level README)

- **Monthly drift reports** for a curated set of public skills.
- **Model-release-triggered reports** — re-run receipts when a new model version
  ships, so drift is caught at the release rather than months later.

Each published report is reproducible: it names the exact model, skill
`content_hash`, suite `suite_hash`, and judge settings, and links the receipts it
was computed from.
