Benchmark gap calculator

Type two benchmark scores and the number of questions, and see whether the gap is bigger than the benchmark's own sampling noise.

Method frozen 7 Oct 2026: Wilson 95% intervals and Newcombe's hybrid difference, written out in gap.js; the verdict words are the methodology page's.

Two scores (item noise)

Repeated runs (Driftproof's band rule)

Mean and standard deviation in percent, and the run count, per arm. This is the rule the published reports use: bands that do not overlap read separated. Methodology.

What this does not tell you

  • Item noise is not run noise: the two tabs answer different questions and use different rules.
  • No separation detected is not equal ability: it means this sample size could not tell them apart.
  • Both intervals assume independent questions.
