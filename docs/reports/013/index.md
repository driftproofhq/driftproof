## How did each comparison come out, run by run?

With the skill, Claude Sonnet 5.5 was never clearly higher or lower than Claude Opus 5.5 in nine results, and five of them had too few answers to tell. It scored clearly higher than Claude Sonnet 5 on documentation in two of three runs.

| Claude Sonnet 5.5 against Claude Sonnet 5 | documentation | clearly higher | too few answers to tell | clearly higher |

| Claude Opus 5.5 against Report 011 | documentation | too few answers to tell | clearly higher | clearly higher |

The nine comparisons are three tasks times three pairings. Five of the nine comparisons did not give the same result in every repeat: Claude Sonnet 5.5 against Claude Sonnet 5 on code review, git workflow and documentation; Claude Sonnet 5.5 against Claude Opus 5.5 on code review; and Claude Opus 5.5 against Report 011 on documentation. Three of those five changed only between “too few answers to tell” and “no clear difference”: Claude Sonnet 5.5 against Claude Sonnet 5 on code review and git workflow; and Claude Sonnet 5.5 against Claude Opus 5.5 on code review.

**Clearly higher** (or lower): in that run the spread of scores for the two models did not overlap, and their averages were at least 0.05 apart. A model’s spread is its average plus or minus the usual variation of its answers’ scores.

**No clear difference**: there were enough answers to see a gap of 0.05, and the spreads overlapped or the gap was smaller.

**Too few answers to tell**: the scores were too spread out, or too few, to see a gap of 0.05 either way. It does not mean the models scored the same.
