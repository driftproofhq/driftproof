Report 014: Claude Haiku 5.5 on release day, three skills

What did Report 014 find?

  • What we tested. Claude Haiku 5.5 came out on 7 Oct. We ran it and Claude Haiku 4.5 on three skills, three times each.
  • What we found. On Claude Haiku 5.5 no skill clearly helped in two or more of three repeats. Documentation clearly helped Claude Haiku 4.5 in two of three; on Haiku 5.5 all three had too few answers to tell, so these runs cannot say whether it still helps. Code review and git workflow did not clearly help either model in two or more repeats.
  • Repeats matter. Four of six model and task pairs changed reading between repeats.
  • What it doesn't show. One task per skill and few answers: nothing about other work, and no model ranking.
