How we test a skill

A skill gives an AI extra instructions. We ask: do those instructions improve its written answers?

  1. The task Same question. Same AI.

    Driftproof writes tasks from the skill description.

    Give the AI a task
  2. The comparison Change the instructions
    With the skill Written answer
    Without the skill Written answer

    Repeat both ways to see how much answers vary.

  3. The result Judge each task
    Haiku 5.5 scores the answers

    A clear drop on any task takes priority. Otherwise, a better task can mean the skill helped. When answers vary too much, we cannot settle the result.

These tests cover written answers, not installation, tool use or how useful a skill is in general.

Method

The frozen Skills.sh all-time install snapshot selects the plain list, with the recorded tie rule and exclusions. Popularity is reported installs, not quality or unique people. Each pinned skill has three committed text tasks written by Driftproof from its own description and README. Suites were fixed before these runs.

Both model sets use Haiku 5.5 as judge.

The eval account's configuration was read and found clean before and after each run, not during it.

Each task has with-skill and baseline arms. The sampler starts at 3 generation draws and can extend to 10; each measured draw has 5 judge samples. It stops under the recorded spread and stability rule. Every retained judge output is parsed again before publication, and scores and aggregates must match the sealed receipt.

Each measurable result is the reader's per-task reading, not a reading of the overall mean difference. A separated-down task takes precedence over a separated-up task. The table keeps each reader explanation and named task bands together. A point band may reflect the judge's score grid.

This table departs from the usual value-per-token layout: it reports independent receipt verdicts for measurable results, with no new value ratio, cross-skill scale or model-versus-model causal claim. No deterministic post-checks were defined for these suites.
