The six report types

All six use the same rule: a verdict is claimed only when the two ranges do not overlap and the move clears the floor. They differ in what moves underneath the skill, or, in the value report, in which axes are measured.

Release drift report

Asks whether a skill's verdict holds when the model version underneath it changes. Example: Report 008.

Instrument re-measurement report

Moves neither, and re-runs cells an earlier report published on a corrected measuring device. Example: Report 007.

Revision drift report

Holds everything underneath still and moves the skill's own text. Example: Report 006.

Value report

Holds the substrate still and asks what a skill costs to run, alongside whether it helps. Example: Report 005.

Capability-gap report

Asks whether it holds on a higher tier of the same provider. Example: Report 004.

Substrate durability report

Asks whether it holds across a change of substrate: a different model behind a different vendor CLI. Example: Report 002.
