Read a results file

Drop another tool's results file. Read its scores and exclusions here.

The file stays on your machine. This page calls no model and spends no tokens.

This reader needs JavaScript. Without it, use the CLI on your machine:

driftproof import results.json --from skillgrade

Replace the file path and format. See the supported formats and commands.

What this page reads

Choose agent-skills-eval, skillgrade, claude-plugin-eval or skill-creator. Harbor needs a job directory. NVIDIA cards need a git checkout. Use the CLI for those formats.

The result is an analysis, not a sealed receipt. Source scores are declarations. This page does not verify model execution or read a verdict about effects.

After loading, this reader makes no requests. It saves no file data in the address, cookies or browser storage. Browser extensions and other browser features are outside this page's control.
