find-skills

The prompts and scoring guides used to test find-skills, with each report’s findings and limits.

vercel-labs/skills

Helps users discover and install agent skills when they ask questions like "how do I do X", "find a skill for X", "is there a skill that can…", or express interest in extending capabilities. This skill should be used when the user is looking for functionality that might exist as an installable skill.

About this skill and its measurements

For find-skills, agent-browser, hyperframes and hyperframes-registry, these text tasks test the router's written response, not the delegated skill. Their results are excluded from verdict counts.

The task

search

Link to this task

Written responses only. No tool execution, installed dependencies, media generation or cloud services are tested.

What we asked

Do not use tools, access the network, write files, run commands or install anything. Answer only in text using the supplied facts. I need a skill for React performance work. Supplied candidates: vercel-labs/agent-skills@react-best-practices, 1200 installs, repository 800 stars; unknown/demo@react-speed, 12 installs, 3 stars. Recommend a candidate and show the proposed install command, without installing.
The scoring guide
Driftproof-authored text-only evaluation, not an author-supplied benchmark or an installed-tool test.
