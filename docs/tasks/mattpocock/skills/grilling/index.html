The task

frontier

Link to this task

Written responses only. No tool execution, installed dependencies, media generation or cloud services are tested.

What we asked

Do not use tools, access the network, write files, run commands or install anything. Answer only in text using the supplied facts. Stress-test a plan for automated digest delivery. Audience and delivery channel are undecided. Provider choice depends on channel; retention depends on audience. Give the first interview round.

Driftproof-authored text-only evaluation, not an author-supplied benchmark or an installed-tool test. Link to this task

What we asked
