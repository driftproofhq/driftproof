The task

decision

Link to this task

Written responses only. No tool execution, installed dependencies, media generation or cloud services are tested.

What we asked

Do not use tools, access the network, write files, run commands or install anything. Answer only in text using the supplied facts. Interview me about a reservation design and propose documentation to preserve decisions. Facts: a hold lasts 10 minutes; capture happens only at confirmation. The term booking is currently used for both a hold and a confirmed reservation.
