plan

Link to this task

Written responses only. No tool execution, installed dependencies, media generation or cloud services are tested.

What we asked

Do not use tools, access the network, write files, run commands or install anything. Answer only in text using the supplied facts. Stress-test this plan in your first written interview round: replace all scheduled billing jobs with events next week. Duplicate handling, rollback and the migration budget are undecided.

The task

constraint

Link to this task

Written responses only. No tool execution, installed dependencies, media generation or cloud services are tested.

What we asked

Do not use tools, access the network, write files, run commands or install anything. Answer only in text using the supplied facts. Interview me about migrating a read-only dashboard. Facts: queries are slow; caching policy is unset; the database cannot change. Ask only questions whose answers do not depend on other unanswered choices.

The task

followup

Link to this task

Written responses only. No tool execution, installed dependencies, media generation or cloud services are tested.

What we asked

Do not use tools, access the network, write files, run commands or install anything. Answer only in text using the supplied facts. Continue the interview. We already agreed on a weekly digest, an opt-in audience and a 24-hour rollback window. Delivery channel is undecided; provider selection depends on the channel.
